# UnPaged Claude Plugins

Claude Code plugins by [UnPaged](https://unpaged.io) — the visual canvas where humans and agents work on the same board.

## Install

```
/plugin marketplace add iliedanila/unpaged-claude-plugins
/plugin install visual-plan@unpaged
```

## Plugins

| Plugin | What it does |
| --- | --- |
| [visual-plan](plugins/visual-plan) | Renders Claude Code plans as visual boards on UnPaged. Review the plan on a canvas, comment on the pieces, and watch the board flip to *executing* when you approve. |
